This library contains reusable, public prompts for academic writing and publication workflows. Each prompt is a starting framework rather than permission to alter evidence, make declarations, contact third parties, or submit material.

## Figures and tables

- [**Academic Figure and Table Review & Revision**](/ai/prompts/figure-table-review/) — A publication-level audit and revision prompt covering correctness, visual design, layout, titles, notes, notation, abbreviations, self-containment, reader comprehension, and narrative value.

## Usage

1. Open the relevant prompt and copy the master prompt.
2. Supply the artifact, manuscript context, intended takeaway, and any journal constraints.
3. Attach source data or code when numerical verification is required.
4. Treat proposed substantive changes as recommendations requiring author review.

Project-specific instructions, confidential drafts, referee correspondence, and active submission strategy do not belong in this public library.
