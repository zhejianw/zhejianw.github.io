# Semantic Review Checklist — One Layer Pair

Use this after a mechanical parity check. A successful build is not evidence of semantic equivalence.

## A. Pair identity

- [ ] Correct Chinese source and English counterpart.
- [ ] Correct source blob SHA.
- [ ] Correct routes and prompt layer.
- [ ] Same anchor order.
- [ ] Same prompt-block count and order.

## B. Functional equivalence

For every changed prompt:

- [ ] The same artifact or research layer is being worked on.
- [ ] The same cognitive posture is preserved.
- [ ] The task is neither broadened nor narrowed.
- [ ] A hard constraint has not become a suggestion.
- [ ] A suggestion has not become mandatory.
- [ ] The model retains the same discretion.
- [ ] Every material “do not” remains operative.
- [ ] The same evidence status and preservation rule applies.
- [ ] The same output files, summaries, paths, classifications, or decisions are required.
- [ ] The same routing / return / stopping logic remains.

## C. Writing quality

- [ ] Natural senior applied-micro English.
- [ ] No literal translation that changes the economics meaning.
- [ ] Standard economics terminology retained where more precise.
- [ ] No extra AI boilerplate, hedging, or safety language.
- [ ] No silent shortening or checklist expansion.
- [ ] No translator note in the published page.
- [ ] No unintended CJK residue.

## D. Layer-specific checks

### Setup
- [ ] CLAUDE / PROJECT / HANDOFF roles remain distinct.
- [ ] Workflow remains directional but reversible.

### Notes
- [ ] Positive, null, unstable, contradictory, failed, and dead-end evidence treatment is unchanged.
- [ ] H1 / H2 / V1 / V2 / H3 / C1 / X1 remain distinct.

### Routing
- [ ] Only paper-level high-information questions reopen evidence.
- [ ] Existing-data, new-data, untestable, and fatal branches remain distinct.
- [ ] Candidate Brief still receives reverse audit.

### Brief
- [ ] Ceiling remains distinct from acceptance probability.
- [ ] Journal fit does not lower scientific standards.

### Manuscript
- [ ] Quick and Deep postures remain distinct.
- [ ] Adversarial, convergence, substantive, and production-QA prompts are not blurred.

### Submission
- [ ] No actual submission without explicit authorization.
- [ ] Replication remains clean-room.
- [ ] Snapshot remains minimal, portable, sufficient, and immutable after freezing.
